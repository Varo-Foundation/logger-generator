Sample logger data

Realistic temperature logger downloads, made up from scratch

Files laid out exactly like a vaccine fridge logger's USB drive, from a simulation of the fridge, its door, its power and its faults. Use them to test software that reads logger data, to run training sessions and demos, or to reproduce a problem without anyone sharing real files.

  • Nothing real. No real device, facility or person, ever.
  • Made in your browser. Nothing is uploaded or stored.
  • Fresh every time. Each download gets a new seed; the same seed always gives the same files.

Missing your logger? Send us a file

        

          You don't need to write any code. If your programme uses a logger or fridge we don't cover,
          or your devices write something slightly different, email an example download to
          support@varofoundation.org
          and we'll add it. One file from any commercially available device is enough to start.
        

        

          We use the file only to learn the format. It never goes into the repository, and everything
          published is generated from scratch. Please email files rather than posting them publicly:
          real downloads usually carry serial numbers and facility names.
        

      

      

        
About

        

          Built by the Varo Foundation as the shared test data
          for the Varo apps and Pogo LT, and open source under the MIT license. Its EMS model builds on
          Benson Miller's open-source ems-data-simulator.
        

        

          It covers commercially available devices with public formats only. The
          README documents every
          format field by field, every scenario and the command-line options.
